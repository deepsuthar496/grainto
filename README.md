# Grainto

Grainto is a texture and gradient generator built for creators, designers, and developers. Easily generate noise, gradients, and visual effects to bring your designs to life.

## Features

- **Noise Generator**: Create customizable noise textures.
- **Gradient Generator**: Build beautiful, dynamic gradients.
- **Effects Generator**: Apply varied visual effects to your elements.
- **Export Options**: Export your creations as images or animations.

## Tech Stack

This project is built using:
- [Vite](https://vitejs.dev/)
- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)

## Getting Started

To get started with Grainto locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/deepsuthar496/grainto.git
   ```

2. Navigate into the project directory:
   ```bash
   cd grainto
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
   (Alternatively, use `npm start` or the respective script in package.json to start the server)

5. Open your browser and go to `http://localhost:5173` to see Grainto in action!
